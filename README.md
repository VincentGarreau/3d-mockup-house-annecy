# Maquette 3D — duplex Annecy-le-Vieux

Maquette interactive (three.js) du duplex lot 306, 2 allée de la Bergeronnette.
`index.html` (généré par la maquette) et three.js 0.160 embarqué dans `vendor/` (licence MIT), servis par `server.js` (Node, sans dépendance).

- Déploiement Railway : `npm start` (port fourni par `PORT`).
- Accès protégé (optionnel) : variable `BASIC_AUTH=utilisateur:motdepasse`.
- Pages non indexées par les moteurs de recherche (`X-Robots-Tag`).
